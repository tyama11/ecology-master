# 生態系・光合成マスター (Ecology & Photosynthesis Master)

高校生物の「光合成・物質生産」と「生態系・環境問題」を楽しくマスターできるインタラクティブ学習アプリです！

## 🌟 主な機能

- **2つの学習分野**:
  - **光合成・物質生産**: 葉緑体、光合成速度、光補償点・光飽和点、物質生産・一次遷移・二次遷移などの重要用語・仕組みをパズル感覚で配置して学べます。
  - **生態系・環境問題**: 垂直分布（森林限界）、河川の自浄作用、富栄養化（アオコ・赤潮）、地球温暖化や生物多様性などのつながりを視覚的に理解できます。
- **3つの難易度**:
  - **かんたん (Easy)**: 可愛いアイコンとヒント付きでじっくり学べます。
  - **ふつう (Normal)**: 実戦形式の標準モード。すべてクリアすると鬼モードが解放されます！
  - **鬼 (Oni) 👹**: 制限時間内に次々出題される問題を解き続けるタイムアタックモード。連続正解でタイムボーナス！あなたの限界と称号に挑戦しよう。
- **完全無料・インストール不要**: ブラウザですぐに遊べます。
